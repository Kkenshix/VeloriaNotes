# Üçüncü taraf yazılımlar

Veloria Notes'un bu depodaki kendi kaynak kodu MIT Lisansı ile yayımlanır.

Projede kullanılan veya derleme/kurulum sırasında edinilen başlıca açık kaynak bileşenler:

- **Electron** — MIT License — masaüstü çalışma zamanı.
- **electron-builder** — MIT License — Windows dağıtım paketinin oluşturulması.
- **NSIS** — zlib/libpng License — electron-builder tarafından Windows kurulum EXE'si üretiminde kullanılır.
- **rcedit** — MIT License — Windows EXE metadata ve simge düzenleme işlemleri.
- **Go toolchain / standard library** — BSD-style License — küçük web kurucusunun derlenmesinde kullanılır.

Web kurucusu, ilk kurulum sırasında Electron çalışma zamanını resmi Electron dağıtımından indirir ve yayımlanmış SHA-256 listesiyle doğrular. Üçüncü taraf adları ve ticari markaları ilgili sahiplerine aittir. Dağıtım yapılırken ilgili lisans bildirimleri korunmalıdır.
